# Big Data Project 2026 - Ανάλυση Δεδομένων με Apache Spark

Αυτό το αποθετήριο περιέχει την υλοποίηση της τελικής εργασίας για το μάθημα των Μεγάλων Δεδομένων. Αντικείμενο του project είναι η επεξεργασία και ανάλυση δεδομένων μεταφορών (Taxi Trips) με χρήση RDD, DataFrames API και Spark SQL σε περιβάλλον distributed cluster.

## 📁 Δομή Αποθετηρίου
* **`jobs/`**: Περιλαμβάνει τα Python scripts για το EDA και τα Ερωτήματα Q1 έως Q6 (υλοποιήσεις με DataFrames και SQL).
* **`scripts/`**: Bash scripts για την αυτοματοποίηση της υποβολής των jobs στο cluster και τη διαχείριση του HDFS.
* **`results/`**: Συγκεντρωτικά αποτελέσματα, πλάνα εκτέλεσης (plans), διαγράμματα (plots) και screenshots της εκτέλεσης.
