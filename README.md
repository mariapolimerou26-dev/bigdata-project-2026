# Big Data Project 2026 - Ανάλυση Δεδομένων με Apache Spark

Αυτό το αποθετήριο περιέχει την υλοποίηση της τελικής εργασίας για το μάθημα Συστήματα Διαχείρισης Μεγάλου Όγκου Δεδομένων (2026). Αντικείμενο του project είναι η επεξεργασία και ανάλυση μεγάλου όγκου δεδομένων μεταφορών (Taxi Trips) με χρήση RDD, DataFrames API και Spark SQL σε περιβάλλον κατανεμημένου cluster (YARN).

## Δομή Αποθετηρίου
* **`jobs/`**: Περιλαμβάνει τα τελικά Python scripts για το EDA και τα Ερωτήματα Q1 έως Q6.
* **`results/`**: Συγκεντρωτικά αποτελέσματα, πλάνα εκτέλεσης (plans), διαγράμματα (plots) και screenshots από την επιτυχή εκτέλεση στο cluster.
* **`scripts/`**: Bash και βοηθητικά scripts για την αυτοματοποίηση της υποβολής των jobs στο cluster και τη διαχείριση του HDFS.
* **`RUNBOOK.md`**: Ο επίσημος οδηγός αναπαραγωγής αποτελεσμάτων βήμα προς βήμα σε λιγότερο από 30 λεπτά.
* **`LLM_USAGE.md`**: Δήλωση χρήσης εργαλείων Τεχνητής Νοημοσύνης (LLMs) για τη μορφοποίηση και υποστήριξη του project.
* **`Report.pdf`**: Η τελική τεχνική αναφορά της εργασίας με τα συμπεράσματα και τις συγκρίσεις των χρόνων εκτέλεσης.

## Οδηγίες Εκτέλεσης
Για αναλυτικές οδηγίες σχετικά με την αναπαραγωγή των αποτελεσμάτων και τους χρόνους εκτέλεσης, συμβουλευτείτε το αρχείο **`RUNBOOK.md`**.
